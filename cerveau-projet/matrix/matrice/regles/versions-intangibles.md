# REGLE MATRICE -- FICHIERS DES AUTRES VERSIONS INTANGIBLES

> Source : directive createur 2026-09-08 (correction E-048 -> E-049).
> Les fichiers des autres versions APPARTIENNENT aux autres versions.

## La regle

- La Matrice ne touche JAMAIS aux fichiers des autres versions (v1 session,
  v2 freelance) : `AGENTS-activite-recente.md`, `AGENTS-historique.md`,
  `AGENTS-historique-v2.md`, encarts v1/v2 d'AGENTS.md, tout ce qui vit hors
  de `matrix/` et appartient a la v1 ou la v2.
- La v3 possede SES propres fichiers : le journal multi-encarts v3 (E-049) est
  un NOUVEAU fichier dans `matrix/` -- il ne remplace rien, il n'edite rien d'existant.
- Lire n'est pas toucher : la Matrice PEUT lire les fichiers des autres versions
  pour comprendre (source d'apprentissage), elle ne les modifie JAMAIS.

## Pourquoi

Chaque version est un systeme vivant avec ses propres outils et contrats.
Modifier un fichier d'une autre version = corrompre un systeme etranger.
La cohabitation exige l'intangibilite mutuelle.
