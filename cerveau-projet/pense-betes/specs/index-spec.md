## Comment creer une nouvelle spec

1. Reperer le **pense-bete source** (dans `pense-betes/`)
2. Copier le [spec-template.md](spec-template.md)
3. Renommer selon la convention : `spec-[theme].[id].[class].[statut].md`
4. Remplir toutes les sections
5. Passer par le cycle RVAV
