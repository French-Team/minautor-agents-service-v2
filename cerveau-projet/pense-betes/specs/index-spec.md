## Comment créer une nouvelle spec

1. Repérer le **pense-bête source** (dans `pense-betes/`)
2. Copier le [spec-template.md](spec-template.md)
3. Renommer selon la convention : `spec-[thème].[id].[class].[statut].md`
4. Remplir toutes les sections
5. Passer par le cycle RVAV
