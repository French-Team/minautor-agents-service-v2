## Résumé rapide

| Règle | Description |
|---|---|
| **Profondeur = Niveau** | Le niveau est défini par la profondeur dans l'arbre |
| **Plateforme obligatoire** | Chaque dossier a un fichier point d'entrée |
| **Réorganisation** | Modifier les appels dans la plateforme, jamais déplacer le code |
| **Extension verticale** | Nouveau niveau = nouveau sous-dossier |
| **Single entry** | Une seule plateforme par dossier |
| **Modules autonomes** | Pas de ressources partagées entre dossiers |
