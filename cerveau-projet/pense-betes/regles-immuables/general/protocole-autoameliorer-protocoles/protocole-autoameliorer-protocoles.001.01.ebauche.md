# Protocole -- Auto-Ameliorer les Protocoles
---

## Objectif

Permettre aux protocoles de s'ameliorer en continu, en les adaptant aux besoins du projet.

---

## Prerequis

- Lire `regles-immuables/general/index-regles-general.md` pour connaitre les protocoles
- Identifier les besoins non couverts
- Lire `convention-autoamelioration.md` pour les principes

---

## Etapes

### Etape 1 -- Diagnostiquer l'etat des protocoles

```
1. Lire regles-immuables/general/index-regles-general.md
2. Pour chaque protocole :
   a. Verifier s'il est a jour
   b. Verifier s'il est respecte
   c. Identifier les ameliorations necessaires
3. Identifier les protocoles manquants
```

### Etape 2 -- Ameliorer les protocoles existants

```
Pour chaque protocole :
1. Analyser les retours d'utilisation
2. Identifier les ameliorations possibles
3. Appliquer les ameliorations
4. Mettre a jour la documentation
5. Valider par RVAV
```

### Etape 3 -- Creer de nouveaux protocoles

```
Pour chaque besoin non couvert :
1. Creer un pense-bete
2. Creer une spec
3. Creer un todo
4. Developper le protocole
5. Tester le protocole
6. Documenter le protocole
7. Integrer le protocole
```

### Etape 4 -- Archiver les protocoles obsoletes

```
Pour chaque protocole obsolete :
1. Verifier qu'il n'est plus utilise
2. Le deplacer dans un dossier d'archive
3. Mettre a jour la documentation
4. Signaler l'archivage
```

### Etape 5 -- Valider la coherence

```
1. Verifier que tous les protocoles sont a jour
2. Verifier que la documentation est complete
3. Verifier que les protocoles sont coherents
4. Valider par RVAV
```

---

## RVAV

Appliquer le cycle complet a chaque etape critique :
- [rechercher] -- verifier les impacts
- [verifier] -- confirmer la coherence
- [analyser] -- valider les consequences
- [valider] -- approuver l'amelioration
