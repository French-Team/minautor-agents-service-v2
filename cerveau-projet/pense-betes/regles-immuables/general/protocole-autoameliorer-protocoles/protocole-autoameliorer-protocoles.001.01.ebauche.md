# Protocole — Auto-Améliorer les Protocoles
---

## Objectif

Permettre aux protocoles de s'améliorer en continu, en les adaptant aux besoins du projet.

---

## Prérequis

- Lire `regles-immuables/general/index-regles-general.md` pour connaître les protocoles
- Identifier les besoins non couverts
- Lire `convention-autoamelioration.md` pour les principes

---

## Étapes

### Étape 1 — Diagnostiquer l'état des protocoles

```
1. Lire regles-immuables/general/index-regles-general.md
2. Pour chaque protocole :
   a. Vérifier s'il est à jour
   b. Vérifier s'il est respecté
   c. Identifier les améliorations nécessaires
3. Identifier les protocoles manquants
```

### Étape 2 — Améliorer les protocoles existants

```
Pour chaque protocole :
1. Analyser les retours d'utilisation
2. Identifier les améliorations possibles
3. Appliquer les améliorations
4. Mettre à jour la documentation
5. Valider par RVAV
```

### Étape 3 — Créer de nouveaux protocoles

```
Pour chaque besoin non couvert :
1. Créer un pense-bête
2. Créer une spec
3. Créer un todo
4. Développer le protocole
5. Tester le protocole
6. Documenter le protocole
7. Intégrer le protocole
```

### Étape 4 — Archiver les protocoles obsolètes

```
Pour chaque protocole obsolète :
1. Vérifier qu'il n'est plus utilisé
2. Le déplacer dans un dossier d'archive
3. Mettre à jour la documentation
4. Signaler l'archivage
```

### Étape 5 — Valider la cohérence

```
1. Vérifier que tous les protocoles sont à jour
2. Vérifier que la documentation est complète
3. Vérifier que les protocoles sont cohérents
4. Valider par RVAV
```

---

## RVAV

Appliquer le cycle complet à chaque étape critique :
- [rechercher] — vérifier les impacts
- [vérifier] — confirmer la cohérence
- [analyser] — valider les conséquences
- [valider] — approuver l'amélioration
