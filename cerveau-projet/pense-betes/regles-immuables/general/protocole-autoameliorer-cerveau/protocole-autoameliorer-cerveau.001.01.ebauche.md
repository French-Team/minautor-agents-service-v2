# Protocole -- Auto-Ameliorer le Cerveau
---

## Objectif

Permettre au cerveau-projet de s'ameliorer en continu, en veillant a ce que toutes les sections restent coherentes et a jour.

---

## Prerequis

- Lire `index-cerveau.md` pour comprendre l'etat actuel
- Lire `demarrer.md` pour connaitre les protocoles
- Lire `convention-autoamelioration.md` pour les principes
- Lire `protocole-gestion-defaillances.md` pour les defaillances

---

## Etapes

### Etape 1 -- Diagnostiquer l'etat du cerveau

```
1. Lire index-cerveau.md
2. Verifier le statut de chaque section :
   - conventions : X/Y completes
   - regles-immuables : X regles creees
   - protocoles : X protocoles crees
   - recherches-web : structure creee
   - classeur-variables : structure creee
3. Identifier les sections incompletes ou obsoletes
4. Noter les prochaines etapes
```

### Etape 2 -- Identifier les ameliorations necessaires

```
Pour chaque section, verifier :
1. Est-ce a jour ?
2. Est-ce coherent avec les autres sections ?
3. Est-ce que les agents l'utilisent correctement ?
4. Est-ce qu'il manque des elements ?
```

### Etape 3 -- Planifier les ameliorations

```
1. Lister les ameliorations necessaires
2. Les prioriser (urgent > important > mineur)
3. Creer un pense-bete pour chaque amelioration majeure
4. Creer une spec si necessaire
5. Creer un todo avec les etapes
```

### Etape 4 -- Appliquer les ameliorations

```
Pour chaque amelioration :
1. Appliquer en suivant les conventions
2. Mettre a jour les fichiers concernes
3. Mettre a jour les index
4. Valider par RVAV
```

### Etape 5 -- Valider la coherence

```
1. Verifier que toutes les sections sont coherentes
2. Verifier que les liens sont corrects
3. Verifier que les conventions sont respectees
4. Verifier que les protocoles sont a jour
5. Appliquer protocole-gestion-defaillances si defaillance detectee
```

### Etape 6 -- Documenter l'amelioration

```
1. Mettre a jour index-cerveau.md (prochaines etapes)
2. Mettre a jour le fichier concerne (historique)
3. Ajouter une entree dans les recherches-web si necessaire
4. Signer : "[nom-agent] -- [date]"
```

---

## RVAV

Appliquer le cycle complet a chaque etape critique :
- [rechercher] -- verifier les impacts
- [verifier] -- confirmer la coherence
- [analyser] -- valider les consequences
- [valider] -- approuver l'amelioration

---

## Pieges courants

| Piege | Eviter |
|---|---|
| Ameliorer sans verifier | Toujours lire les fichiers concernes |
| Creer des doublons | Verifier l'existence avant de creer |
| Oublier les dependances | Utiliser code_searcher |
| Ne pas documenter | Toujours mettre a jour l'historique |
