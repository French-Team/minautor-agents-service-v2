# Distinction -- Conventions vs Protocoles
---

## Definitions

| Concept | Nature | Role | Exemple |
|---|---|---|---|
| **Convention** | Explicatif | Guide, explication, reference | `convention-structures.md` explique la structure |
| **Protocole** | Directif | Instruction, ordre, processus | `protocole-demarrer-projet.md` dit quoi faire |

---

## Caracteristiques

### Convention

| Caracteristique | Description |
|---|---|
| **Nature** | Explicatif |
| **Objectif** | Expliquer **comment** faire quelque chose |
| **Utilisation** | Consulter quand on a besoin de guidance |
| **Flexibilite** | Peut etre interpretee selon le contexte |
| **Obligation** | Recommandee, pas obligatoire |
| **Exemple** | "Voici comment structurer un dossier" |

### Protocole

| Caracteristique | Description |
|---|---|
| **Nature** | Directif |
| **Objectif** | Dire **quoi** faire dans une situation donnee |
| **Utilisation** | Suivre quand la situation se presente |
| **Flexibilite** | Peu ou pas de flexibilite |
| **Obligation** | Obligatoire (surtout les "IMMUABLE") |
| **Exemple** | "Avant de commencer, lis AGENTS.md" |

---

## Analogie

### Convention = Manuel de cuisine

```
Le manuel explique :
- Comment tenir un couteau
- Comment emincer un oignon
- Les differentes techniques de cuisson

Tu peux consulter le manuel quand tu veux.
Tu n'es pas oblige de suivre chaque etape exactement.
```

### Protocole = Recette

```
La recette dit :
1. Prechauffer le four a 180 degres C
2. Melanger farine + sucre + oeufs
3. Cuire 25 minutes

Tu dois suivre les etapes dans l'ordre.
Sinon, le gateau ne sera pas bon.
```

## Comment les utiliser ensemble

### Scenario 1 : Creer un nouveau composant

```
1. Consulter convention-structures.md (comment structurer)
2. Suivre protocole-composition.md (quoi faire)
3. Consulter convention-renommage.md (comment nommer)
4. Passer par RVAV (valider)
```

### Scenario 2 : Demarrer un nouveau projet

```
1. Suivre protocole-demarrer-projet.md (quoi faire)
2. Consulter les conventions au besoin (comment faire)
3. Installer les regles immuables (protocole-installer-regles.md)
4. Passer par RVAV (valider)
```

### Scenario 3 : Modifier un fichier existant

```
1. Lire le fichier concerne
2. Consulter les conventions applicables
3. Verifier les dependances
4. Modifier en suivant les regles
5. Passer par RVAV (valider)
```

## Resume

| Question | Reponse |
|---|---|
| **Qu'est-ce qu'une convention ?** | Un guide explicatif |
| **Qu'est-ce qu'un protocole ?** | Une instruction directe |
| **Quand consulter une convention ?** | Quand on a besoin de guidance |
| **Quand suivre un protocole ?** | Quand la situation se presente |
| **Les deux sont-ils obligatoires ?** | Protocoles = oui, Conventions = recommande |
| **Peut-on les melanger ?** | Oui, on les utilise souvent ensemble |
