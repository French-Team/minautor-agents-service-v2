# Distinction — Conventions vs Protocoles
---

## Définitions

| Concept | Nature | Rôle | Exemple |
|---|---|---|---|
| **Convention** | Explicatif | Guide, explication, référence | `convention-structures.md` explique la structure |
| **Protocole** | Directif | Instruction, ordre, processus | `protocole-demarrer-projet.md` dit quoi faire |

---

## Caractéristiques

### Convention

| Caractéristique | Description |
|---|---|
| **Nature** | Explicatif |
| **Objectif** | Expliquer **comment** faire quelque chose |
| **Utilisation** | Consulter quand on a besoin de guidance |
| **Flexibilité** | Peut être interprétée selon le contexte |
| **Obligation** | Recommandée, pas obligatoire |
| **Exemple** | "Voici comment structurer un dossier" |

### Protocole

| Caractéristique | Description |
|---|---|
| **Nature** | Directif |
| **Objectif** | Dire **quoi** faire dans une situation donnée |
| **Utilisation** | Suivre quand la situation se présente |
| **Flexibilité** | Peu ou pas de flexibilité |
| **Obligation** | Obligatoire (surtout les "IMMUABLE") |
| **Exemple** | "Avant de commencer, lis AGENTS.md" |

---

## Analogie

### Convention = Manuel de cuisine

```
Le manuel explique :
- Comment tenir un couteau
- Comment émincer un oignon
- Les différentes techniques de cuisson

Tu peux consulter le manuel quand tu veux.
Tu n'es pas obligé de suivre chaque étape exactement.
```

### Protocole = Recette

```
La recette dit :
1. Préchauffer le four à 180°C
2. Mélanger farine + sucre + oeufs
3. Cuire 25 minutes

Tu dois suivre les étapes dans l'ordre.
Sinon, le gâteau ne sera pas bon.
```

## Comment les utiliser ensemble

### Scénario 1 : Créer un nouveau composant

```
1. Consulter convention-structures.md (comment structurer)
2. Suivre protocole-composition.md (quoi faire)
3. Consulter convention-renommage.md (comment nommer)
4. Passer par RVAV (valider)
```

### Scénario 2 : Démarrer un nouveau projet

```
1. Suivre protocole-demarrer-projet.md (quoi faire)
2. Consulter les conventions au besoin (comment faire)
3. Installer les règles immuables (protocole-installer-regles.md)
4. Passer par RVAV (valider)
```

### Scénario 3 : Modifier un fichier existant

```
1. Lire le fichier concerné
2. Consulter les conventions applicables
3. Vérifier les dépendances
4. Modifier en suivant les règles
5. Passer par RVAV (valider)
```

## Résumé

| Question | Réponse |
|---|---|
| **Qu'est-ce qu'une convention ?** | Un guide explicatif |
| **Qu'est-ce qu'un protocole ?** | Une instruction directe |
| **Quand consulter une convention ?** | Quand on a besoin de guidance |
| **Quand suivre un protocole ?** | Quand la situation se présente |
| **Les deux sont-ils obligatoires ?** | Protocoles = oui, Conventions = recommandé |
| **Peut-on les mélanger ?** | Oui, on les utilise souvent ensemble |
