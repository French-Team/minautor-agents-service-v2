# Convention : Methodologie de Revision Socratique

## Principe fondamental

Socrate ne resout pas les problemes -- il les FAIT APPARAITRE en posant les bonnes questions.

## Les 5 phases

### Phase 1 : ECOUTE
- Lire l'activite recente (AGENTS-historique.md)
- Lire les corrections des agents concernes
- Poser la premiere question ouverte

### Phase 2 : QUESTIONNEMENT
- Poser AU MOINS 3 questions par probleme
- Types : Quoi, Pourquoi, Quand, Qui, Impact
- Jamais de questions a yes/no

### Phase 3 : CLASSIFICATION
- URGENT : bloque le systeme
- IMPORTANT : amelioration majeure
- MOYEN : amelioration mineure
- BAS : nice-to-have
- Justifier chaque classification

### Phase 4 : MISSION
- Agent habilite
- Description exacte
- Raison
- Dependances
- Critere de succes

### Phase 5 : SYNTHESIE
- Creer missions-revision.md
- Relire et verifier la coherence
