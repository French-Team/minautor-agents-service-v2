## POURQUOI CE DOSSIER EST IMPORTANT

La philosophie est le FONDEMENT des decisions.
Si elle est cassee, les agents prennent des decisions incoherentes.

---

## REGLE ABSOLUE

> JE NE MODIFIE JAMAIS un fichier de philosophie sans avoir VERIFIE
> que les agents existants sont toujours coherents avec la nouvelle
> philosophie. La philosophie est le FONDEMENT, pas un detail.

---

## AVANT de commencer

1. **Lire le fichier a modifier EN ENTIER**
2. **Lire les 2 autres fichiers de philosophie** : sont-ils coherents ?
3. **Verifier 1 agent au hasard** : respecte-t-il encore la philosophie ?
4. **Verifier le README** : l'index est-il toujours correct ?

---

## APRES modification

1. **Relire les 2 autres fichiers** : sont-ils toujours coherents ?
2. **Verifier 1 agent** : respecte-t-il la nouvelle philosophie ?
3. **Mettre a jour le README** si necessaire
4. **Mettre a jour la version** dans le frontmatter
5. **Mettre a jour le cahier de dev**

---

## INTERDICTIONS

| Interdiction | Raison |
|---|---|
| Pas de philosophie incoherente | Les agents sont perdus |
| Pas de suppression de principes fondamentaux | Les agents en dependent |
| Pas de modification sans verification des agents | Risque de desorientation |
| Pas de changement sans mise a jour du README | Perte de coherence |
