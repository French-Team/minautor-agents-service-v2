# Convention -- Auto-Amelioration
---

## Principe Fondamental
---

## Pourquoi l'auto-amelioration ?

| Probleme | Solution |
|---|---|
| Le cerveau devient obsolete | Mise a jour continue |
| Les agents font les memes erreurs | Auto-correction apprise |
| Les outils ne suffisent plus | Amelioration des outils |
| Les conventions ne sont plus adaptees | Revision des conventions |
| Les protocoles ne fonctionnent pas | Amelioration des protocoles |

## Principes d'auto-amelioration

### Principe 1 -- Detection continue

```
Pendant le travail, detecter :
- Les erreurs recurrentes
- Les patterns problematiques
- Les besoins non couverts
- Les ameliorations possibles
```

### Principe 2 -- Documentation obligatoire

```
Toute amelioration doit etre documentee :
- Dans le fichier concerne (historique)
- Dans le fichier de l'agent (corrections.md)
- Dans les index (prochaines etapes)
```

### Principe 3 -- Validation par RVAV

```
Toute amelioration doit passer par RVAV :
- Rechercher les impacts
- Verifier la coherence
- Analyser les consequences
- Valider l'amelioration
```

### Principe 4 -- Tracabilite complete

```
Chaque amelioration doit etre tracable :
- Qui a fait l'amelioration ?
- Quand a-t-elle ete faite ?
- Pourquoi a-t-elle ete faite ?
- Quels sont les impacts ?
```

---

## Cycle d'auto-amelioration

```
1. Detecter un probleme ou un besoin
2. Documenter dans le fichier approprie
3. Creer un protocole si necessaire
4. Appliquer l'amelioration
5. Valider par RVAV
6. Documenter le resultat
7. Mettre a jour les index
```

---

## Frequence d'amelioration

| Type | Frequence | Exemple |
|---|---|---|
| **Correction immediate** | A la detection | Erreur de frappe |
| **Amelioration mineure** | Fin de session | Ajouter une regle |
| **Amelioration majeure** | Quand necessaire | Creer un nouveau protocole |
| **Revision complete** | Periodique | Reviser toutes les conventions |

---

## Indicateurs d'amelioration

### Signaux a detecter

| Signal | Action |
|---|---|
| Meme erreur 2+ fois | Creer une correction |
| Tache repetee | Creer un protocole |
| Besoin non couvert | Creer un outil ou une convention |
| Processus inefficace | Ameliorer le protocole |
| Regle non respectee | Renforcer la regle |

### Metriques a suivre

| Metrique | Objectif |
|---|---|
| Nombre d'erreurs | Diminuer |
| Nombre de protocoles | Augmenter (si necessaire) |
| Couverture des cas | Augmenter |
| Temps de resolution | Diminuer |
